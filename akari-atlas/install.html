Install Akari Atlas

Your world, one journey at a time. Free, no account needed.

🍎 iPhone / iPad

  1. Open Safari (it must be Safari) and go to
    naekitakadoportfolio.github.io/akari-atlas
  2. Tap the Share button (square with an arrow up).
  3. Scroll and tap Add to Home Screen, then Add.
  4. Open Akari Atlas from your home screen. Allow Location when asked for maps and walking directions.
Updates arrive automatically. To share, send the link above.

🤖 Android

Option A · Install from Chrome (easiest)

  1. Open the app link in Chrome.
  2. Tap ⋮ → Install app (or Add to Home screen) → Install.

Option B · APK file

  1. Get the Akari Atlas.apk file (sent to you, e.g. by Messenger, email or Drive).
  2. Tap it. If asked, allow Install unknown apps for that app (Settings → Apps → Special access).
  3. Tap Install, then Open. If Play Protect warns, tap More details → Install anyway.

💻 Computer

Open the link in Chrome or Edge and click the install icon in the address bar.
